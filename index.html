01 Kerberoasting
jsmith → svc_sql TGS hash → cracked offline

Any domain user can request a Kerberos service ticket for any SPN-registered account. The ticket is encrypted with the service account's hash — take it offline and crack it. No lockout, no noise after the initial request.

Tool: impacket-GetUserSPNs Crack: john --format=krb5tgs Result: Summer2024! Event ID: 4769 Enc type: 0x17 (RC4)
↓
02 Password Spray
One password × all accounts → sadmin (Pwn3d!)

One password attempt per account stays under lockout thresholds. Welcome2024! hit sadmin — a Domain Admin. One spray, zero lockouts, Domain Admin compromised.

Tool: nxc smb Target: sadmin Result: (Pwn3d!) Event ID: 4625 + 4624 Wazuh: Rule 92652
↓
03 DCSync Dump
sadmin → every NTLM hash in the domain

Domain Admin credentials used to impersonate DC replication and extract all hashes from NTDS.dit. Administrator hash captured. krbtgt hash captured — enabling Golden Ticket persistence.

Tool: impacket-secretsdump Protocol: DRSUAPI replication Captured: all domain hashes Event ID: 4662 krbtgt: captured
↓
04 Pass-the-Hash
Administrator hash → SYSTEM on DC — no password needed

NTLM authentication accepts the hash directly — no cracking needed. psexec authenticated with the hash, uploaded a service binary to ADMIN$, and returned a SYSTEM shell.

Tool: impacket-psexec -hashes whoami: nt authority\system Event ID: 4624 Type 3 NTLM Wazuh: Rule 92652 Time from start: <10 min
